# Seguridad

No publique vulnerabilidades, datos de huéspedes ni credenciales en issues.

Reporte el hallazgo de forma privada al propietario del repositorio e incluya una descripción reproducible, impacto, versión o commit afectado y mitigación sugerida. No incluya datos personales reales. El responsable debe acusar recibo en dos días hábiles, clasificar la severidad y coordinar una fecha de corrección antes de divulgar detalles.

Si una credencial aparece en el código o historial, debe revocarse en el proveedor. Eliminarla del último commit no basta.
